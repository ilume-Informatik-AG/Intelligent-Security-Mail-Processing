**Intelligent Security Mail Processing based on Camunda 8** — by ilume Informatik AG

## About the solution

AI Mail Guardian gives employees a fast, reliable answer to one simple question: is this email safe or not? Users forward a suspicious email with a single click, and Camunda 8 takes over. The process retrieves headers and metadata via Microsoft Graph, masks personal data such as names before any AI processing (privacy by design), and runs an LLM-based threat assessment on AWS Bedrock with a single EU-hosted data processor. Phishing, CEO fraud, malware, scams and other threats are classified and rated by severity.

The result is a Guardian Report — an HTML email with a clear verdict and concrete recommended actions. Responses always stay inside the organization, so external senders can never confirm that the analysis mailbox exists.
